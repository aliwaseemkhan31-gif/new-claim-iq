# ClaimIQ Enterprise — backend dependencies
#
# Compatible-release pins (~=) allow patch updates while preventing surprise
# major bumps. `requirements.lock.txt` is generated inside the image with
# `pip freeze` and is what an air-gapped deployment installs from — see
# docs/DEPLOYMENT.md.
#
# Every package here works without network access at runtime. Nothing in this
# list calls out to a hosted service.

# --- Framework -------------------------------------------------------------
# Lower bounds rather than compatible-release pins. The original `~=` pins were
# mutually unsatisfiable — django-filter and the django-celery-* packages had
# not yet released versions compatible with Django 5.2 at the pinned
# revisions, and pip resolution failed outright. Lower bounds let a fresh
# install resolve; `requirements.lock.txt`, generated in the image, is what an
# air-gapped deployment installs from.
Django>=5.2,<5.3
djangorestframework>=3.16
django-cors-headers>=4.7
django-filter>=25.1
psycopg[binary,pool]>=3.2

# --- Vectors ---------------------------------------------------------------

# --- Background processing -------------------------------------------------

# --- Server ----------------------------------------------------------------
